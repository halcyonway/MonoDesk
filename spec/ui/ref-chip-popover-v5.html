ref chip + popover v5

v4 痛点：chip 显示短标签（domain / key 末段），读者看不出 source； popover 三 section 太重（type badge + URL + Title + Description）。 v5 改：chip 显示 完整字段 + emoji icon；popover 简化，去掉 type badge section + chip 已展示的 Title 也不再重复。

1. chip 形态（v4 → v5 对比）

v4 短标签 → v5 完整字段 + emoji

参考 github.com （v4）vs 🔗NVIDIA 官网 （v5）。

v5 chip 走 sans 字体（不是 mono），完整字段。emoji 由 type 决定（link=🔗 / memory=📒 / snippet=💬 / tool=🔧）。 视觉稿里 emoji 用 Apple Color Emoji / Segoe UI Emoji 字体回退链。

2. type=link popover（v5 简化）

link — 只剩 URL section
了解更多 🔗NVIDIA 官网 和 🔗Playwright Trace Viewer。
URL
https://www.nvidia.com/en-us/

v5：没有 type badge section（emoji 已经在 chip 里）， 没有 Title section（"NVIDIA 官网" 已在 chip 里）。 popover 只剩 URL，300px 宽（v4 是 340px）。

7. chip 长度上限（24 字符）

长 title 截断
参考 🔗NVIDIA 加速计算完整介绍文档、 📒蚂蚁领投 Pre-A …。

chip 文本统一 24 字符上限，超出加 …。emoji 占 2 字符宽度。 视觉稿里模拟两个 case：第一个 13 字不截；第二个模拟超长 title 截断。

设计细节对照表

chip 字体 v4 mono → v5 sans（系统字体栈）
chip 字号 v4 9.5px → v5 11px（完整字段需要更大字号）
chip 文本策略 v4 shortLabel 截短（domain / key 末段）→ v5 完整字段 + fallback（link: title \|\| domain）
chip icon v4 5 种 SVG（链/笔记本/气泡/扳手/问号）→ v5 inline emoji 字符（🔗/📒/💬/🔧/❓）+ 字体回退链
chip 长度上限 v4 各 type 独立 10/12/14 字符 → v5 统一 24 字符 + truncate(…)
popover 宽度 v4 340px → v5 300px（精简）
popover 内容 v4 type badge + URL + Title + Description → v5 去掉 type badge + chip 已展示的 Title，只剩 chip 没展示的字段
popover padding section padding 8 → 7px
不变 popover 箭头 ::before / favicon Google → site fallback / URL safe scheme / link chip <a> 包整体 / streaming 阶段 raw token
