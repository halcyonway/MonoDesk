设计细节

结构 type badge 行 + N 个 section 行（每行 padding 9×12，底部分隔线）
type badge 4 色圆角胶囊（link绿/memory紫/snippet绿/tool橙），小写 icon + 文字
URL 展示 mono 字体 + favicon 圆形色块 + break-all + overflow-wrap
content/snippet 浅灰背景 + 左侧 2px 竖线 + 底部渐变遮罩表示截断
tool key-value 两列 grid，key 灰色 + val mono
箭头 popover 顶部水平居中（指向 chip 文字中心），11×6px 等腰三角
